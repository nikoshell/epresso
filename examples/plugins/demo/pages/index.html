Plugin demo

Three plugins are wired into this project. Everything below is produced at build time.

Greeter

The greeter plugin adds a greeting() global and a shout filter through its on_setup hook.

{{ greeting() }} · “{{ "shout this" | shout }}”

Quotes

Loaded from a quotes collection registered by a plugin.

    {% for q in get_collection('quotes') %}
  • {{ q.data.text }}
    — {{ q.data.author }}
    • {% endfor %}

Code

The watermark plugin is a pure HTML transform; it stamps a “Made by epresso” pill on every code block. 

pip install epresso
epresso new blog mysite
epresso dev
